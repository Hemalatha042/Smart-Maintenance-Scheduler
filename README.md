\# Smart Maintenance Scheduler



An AI/ML-based predictive maintenance system that helps identify machines that may require maintenance based on machine operating data.



\## Project Overview



The Smart Maintenance Scheduler is designed to support predictive maintenance in industrial environments. It analyzes machine log data and uses machine learning to identify maintenance requirements and provide useful maintenance insights.



\## Features



\- Machine maintenance prediction

\- Failure cause classification

\- Machine log analysis using CSV files

\- Maintenance-required count

\- Top error-code analysis

\- Average running-hours analysis

\- Suggested maintenance date

\- Email alerts for maintenance requirements

\- Excel report download

\- Interactive Streamlit interface
